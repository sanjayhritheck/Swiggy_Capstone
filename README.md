# Swiggy Capstone Analysis

## Project Overview

This project analyzes Swiggy food delivery data using SQL, Python, Google Sheets, and Tableau.

## Parts Completed

### Part A – SQL Analysis
- Database created using SQLite
- SQL foundations and data exploration
- Aggregations and joins
- Reporting queries
- Verification of SQL outputs

### Part B – Data Analysis & Visualization
- Monthly cuisine revenue analysis
- Cuisine-wise revenue comparison
- Revenue targets
- Actual revenue vs target revenue
- Variance analysis

## Tools Used

- Python
- SQLite
- SQL
- Google Sheets
- Tableau Public
- GitHub

## Key Analysis

The analysis covers:
- Revenue by cuisine
- Monthly revenue trends
- Order counts
- Average revenue
- Cuisine performance against revenue targets
